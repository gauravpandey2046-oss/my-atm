# ATM Management System

A Python-based ATM Management System that uses Excel for storing and managing data.

## Features

- Check account balance
- Deposit money
- Withdraw money
- ATM transactions
- Store and manage data using Excel
- Simple and easy-to-use system

## Technologies Used

- Python
- Excel
- VS Code

## Project Files

- `code.py` - Main Python source code
- `Excel.xlsx` - Excel file used for storing data
- `README.md` - Project documentation

## How to Run

1. Install Python.
2. Open this project in VS Code.
3. Open the terminal.
4. Run the Python program.
5. Follow the instructions shown by the program.

## Data Storage

The ATM system uses an Excel file to store and manage user/account data.
